Overview / 项目背景

针对一次性诊断难以处理患者证据缺失与影像—临床冲突的问题，设计融合证据查证、局部验证与受控状态转移的阿尔茨海默病辅助诊断Agent。

Agent architecture / 四阶段流程

以患者证据账本连接诊断与验证：先明确当前证据是否足够，再产生初始诊断，随后开展局部查证，最后决定保持、接受相邻状态转移或安全弃权。

Core contributions / 核心工作

  • Agent Harness & Context Engineering：设计并实现患者级证据账本、规则/ROI验证与有界状态转移，将诊断、证据查证与反馈修正组织为可审计流程；按证据来源、就诊时间与缺失状态管理上下文，通过Visual Grounding关联MRI区域、量化测量与候选诊断。
  • 多模态诊断与可靠性评测：完成诊断骨干的表征训练与diagnosis-only SFT，在患者分组的五折OOF实验中评估Grounded Evidence-State Transition（GEST）；通过相邻状态约束、接受规则与安全弃权控制过度修正，在影子评测中净增加227个正确预测。

Multimodal backbone / 多模态诊断骨干

当前Core路径使用768维MRI embedding、768维文本embedding与3维prior；冻结上游encoder，训练projection与LLaMA的LoRA / norm / bias，将表征对齐至CN / MCI / AD自回归诊断输出。

Shadow evaluation / 影子评测
